# ContextBin (CleanDesk) - User Story (Українська)

## Core Functionality (Основний Функціонал)

### 1. Відправлення файлів у кошик через контекстне меню
**Як** користувач, який цінує чистий робочий стіл,
**Я хочу** легко відправляти файли та папки до системного Кошика Windows через контекстне меню (правий клік),
**Щоб** мій робочий стіл залишався незахаращеним та візуально привабливим, а видалені файли були в одному місці.

### 2. Швидкий доступ до кошика
**Як** користувач, який щойно випадково видалив файл,
**Я хочу** швидко отримати доступ до Кошика Windows через підменю ContextBin у контекстному меню,
**Щоб** я міг відновити свої втрачені файли з мінімальними зусиллями.

### 3. Перегляд вмісту кошика
**Як** користувач, який хоче ефективно керувати видаленими файлами,
**Я хочу** бачити чіткий список елементів у Кошику Windows з деталями, такими як оригінальне розташування, дата видалення та розмір,
**Щоб** я міг легко знайти та вирішити, які файли відновити або остаточно видалити.

### 4. Відновлення файлів
**Як** користувач, який хоче відновити видалений файл,
**Я хочу** мати можливість вибрати один або кілька елементів та відновити їх,
**Щоб** я міг повернути потрібні файли.

### 5. Очищення кошика
**Як** користувач, якому потрібно звільнити місце на диску,
**Я хочу** мати опцію остаточно очистити Кошик Windows через підменю ContextBin у контекстному меню або через UI-додаток,
**Щоб** я міг ефективно керувати своїм сховищем.

## Usability & Integration (Зручність та Інтеграція)

### 6. Безшовна інтеграція з Windows Explorer
**Як** користувач, який хоче безперебійного досвіду,
**Я хочу**, щоб функціонал "ContextBin (CleanDesk)" був глибоко інтегрований у контекстне меню Провідника Windows,
**Щоб** він відчувався як природна частина операційної системи.

### 7. Простота встановлення та видалення
**Як** користувач, який цінує легкість встановлення,
**Я хочу** мати можливість встановити та видалити ContextBin (CleanDesk) за допомогою простого інсталятора,
**Щоб** мені не потрібні були технічні знання для використання або видалення програми.

## Advanced (Майбутні Можливості)

### 8. Автоматичне очищення (опціонально)
**Як** користувач, який хоче автоматизувати догляд за диском,
**Я хочу** мати можливість налаштувати автоматичне очищення кошика за певними правилами (наприклад, файли старші за X днів, або коли розмір кошика перевищує Y ГБ),
**Щоб** мені не доводилося вручну стежити за розміром кошика.

### 9. Безпечне видалення (опціонально)
**Як** користувач, який має конфіденційні файли,
**Я хочу** мати опцію "безпечного видалення" (шреддингу) для вибраних файлів,
**Щоб** бути впевненим, що вони не можуть бути відновлені.
