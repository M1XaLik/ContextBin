# ContextBin (CleanDesk) - User Stories (English)

## Core Functionality

### 1. Sending files to Recycle Bin via Context Menu
**As a** user who values a clean desktop,
**I want to** easily send files and folders to the Windows Recycle Bin via the right-click context menu,
**So that** my desktop remains uncluttered and visually appealing, and deleted files are in one central location.

### 2. Quick Recycle Bin Access
**As a** user who just deleted a file by mistake,
**I want to** quickly access the Windows Recycle Bin through the ContextBin submenu in the context menu,
**So that** I can recover my lost files with minimal effort.

### 3. Viewing Recycle Bin Contents
**As a** user who wants to manage deleted files effectively,
**I want to** see a clear list of items in the Windows Recycle Bin with details like original location, deletion date, and size,
**So that** I can easily find and decide which files to restore or permanently delete.

### 4. Restoring Files
**As a** user who wants to restore a deleted file,
**I want to** be able to select one or more items and restore them to their original location,
**So that** I can get back the files I need.

### 5. Emptying the Recycle Bin
**As a** user who needs to free up disk space,
**I want to** have an option to permanently empty the Windows Recycle Bin via the ContextBin submenu in the context menu or through the UI application,
**So that** I can manage my storage efficiently.

## Usability & Integration

### 6. Seamless Windows Explorer Integration
**As a** user who wants a seamless experience,
**I want the** "ContextBin (CleanDesk)" functionality to be deeply integrated into Windows Explorer's right-click menu,
**So that** it feels like a natural part of the operating system.

### 7. Easy Installation and Uninstallation
**As a** user who values easy installation,
**I want to** be able to install and uninstall ContextBin (CleanDesk) with a simple installer,
**So that** I don't need technical knowledge to use or remove the application.

## Advanced (Future Capabilities)

### 8. Automatic Cleanup (Optional)
**As a** user who wants to automate disk maintenance,
**I want to** be able to configure automatic Recycle Bin cleanup based on certain rules (e.g., files older than X days, or when Recycle Bin size exceeds Y GB),
**So that** I don't have to manually monitor the Recycle Bin size.

### 9. Secure Deletion (Optional)
**As a** user who has sensitive files,
**I want to** have a "secure delete" (shredding) option for selected files,
**So that** I can be confident they cannot be recovered.
